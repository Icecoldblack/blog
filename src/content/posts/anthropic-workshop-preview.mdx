## not an intro session

This wasn't "here's how to use a chatbot." Students went straight to the mental model Anthropic uses for building real agents with Claude:

- **Claude as the reasoning engine:** defining what belongs in a structured task and architecting around it
- **Skills:** standardized, reusable workflows backed by domain-specific playbooks
- **MCP:** connecting Claude to real databases, tools, and systems so it can take action, not just talk
- **Subagents:** role-specific agents that reason and act within a focused, bounded scope

On top of that: prompt engineering that produces reliable output, and live Claude API integration, connecting to the API and making real requests in the room.

![Anthropic's mental model for building with Claude: Skills, MCP, and subagents](/images/claude/claude-architecture.jpg)

## who showed up

70+ students, every experience level. People who'd never touched an API sat next to people already shipping with AI, and both groups left with something working. A turnout and an energy like this doesn't happen by accident. It happens when a community is genuinely hungry to build.

![A packed lecture hall of 70+ Georgia State students at the Anthropic workshop](/images/claude/claude-hall.jpg)

## the result

By the end of the session, students had working projects and a real grasp of what building with AI looks like in practice: agent architecture, not toy demos. Anthropic gave every attendee $20 in API credits to keep building after they walked out the door.

Huge thanks to Tyler Sztuka for making this collaboration happen, and to Anthropic for betting their time on Georgia State's builders.
